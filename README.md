# 📰 Fake Headline Generator (Python)

A fun Python project that generates random, funny fake news headlines using the `random` module.

This project is beginner-friendly and demonstrates:
- Lists in Python
- Random selection
- While loops
- User input handling
- String formatting (f-strings)

---

## 🚀 Features

- Randomly generates humorous headlines
- Uses predefined subjects, actions, and places/things
- Runs in a loop until the user chooses to stop
- Simple and easy-to-understand code

---

## 🛠️ Technologies Used

- Python 3
- Built-in `random` module

---

## 📦 Installation

1. Clone this repository:
git clone https://github.com/Madhavi-13/fake-headline-generator.git

2. Navigate to the project folder:
cd fake-headline-generator

3. Run the Python file:
python filename.py


---

## ▶️ How It Works

The program:
1. Stores subjects, actions, and objects in separate lists.
2. Randomly selects one item from each list.
3. Combines them to create a funny headline.
4. Asks the user if they want another headline.
5. Stops when the user types `no`.

Example output:

Shah Rukh Khan launches a new festival
Do you want to generate another headline? (yes/no):
